# Cypress Automation Testing Assignment

This repository contains automated UI and functional test suites using Cypress for [SauceDemo](https://www.saucedemo.com).

## Project Structure
* `cypress/e2e/task1_functional.cy.js` - Contains 6 core functional tests covering Login, Navigation, and Checkout Form workflows.
* `cypress/e2e/task2_advanced.cy.js` - Demonstrates advanced assertions, element aliases, and custom commands.
* `cypress/support/commands.js` - Includes the custom global `cy.login()` command.

## Prerequisites
Before running the tests, ensure you have [Node.js](https://nodejs.org/) installed.
